# OBJECT : 
## NORMAL DEFINITION : 
Object is an instance of class that is created the the complier by taking the blueprint that is class 
## INTERVIEW DEFINITION : 
An Object is an real time entity which is physically existing in the world 
example : a person , place , thing etc ...
## Syntax : 
  object_name = class_name()

# CLASS : 
## DEFINITION :
A class is an blueprint that is used by the complier to create object in the memory 
A class contains properties and methods
